# aplicacionClics (React Native + Expo)

Código de la app móvil: `src/app/index.tsx`.

## Cómo ejecutarla
1. Crear el proyecto base (fuera de esta carpeta, p. ej. en Documentos):
   `npx create-expo-app aplicacionClics`  → elegir SDK 57 "For learning with Expo Go".
2. Copiar `src/app/index.tsx` de este repositorio sobre el del proyecto creado.
3. `cd aplicacionClics` → `npx expo start` → escanear el QR con Expo Go.
